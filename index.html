执行摘要

本页对比客户鱼在飞（org 7577）在 2026.09 全月（上期）与 2026.10 全月（本期）的客服健康指标（全平台汇总，共 47 项），并以 2026-08 全月作参考基线。三个月均为完整月（逐日探针确认 10-31 有数据），计数 / 金额类按日均折算后再比。总体呈「弃单率降至三个月最低、确认订单放量，但接待承接持续收窄、响应时效明显退坡」的格局——单量与金额基本守住，漏点从「弃单」转移到了「接得住、回得快」。 量稳价平，单均小幅回落：订单数 77,584 → 81,708（+1.9%，日均），日均 2586 → 2636 单（较 8 月日均 2867 单仍低 8.1%）；订单金额 ¥709.2万 → ¥733.7万（+0.1%，日均），日均基本持平；单均 ¥91.4 → ¥89.8（-1.8%）——9 月抬起来的客单价没有掉回去，是金额守住的主因。非 COD 订单占比 34.04% → 33.23%，付款率 91.03% → 91.07%（+0.04pp），支付端稳定。 接待在缩，但接到的更精准：接待买家 4,913 → 4,531（-10.8%，日均），接待覆盖率 6.33% → 5.55%（8 月为 6.76%，三个月连续下探）；其中人工接待 2,631 → 2,372（-12.8%，日均）、机器人 3,489 → 3,337（-7.4%，日均），机器人占比 71.02% → 73.65%（+2.63pp）。少接待带来的不是少成交：接待转化率 11.07% → 12.09%（+1.02pp）（人工 9.16% → 9.36%、机器人 12.58% → 14.20%），接待后下单买家日均 18.1 → 17.7 人，几乎持平——掉的主要是低意向的打招呼流量。 响应时效是本期最明确的一项退坡：人工平均响应 0h52m → 1h27m（+35min / +67.3%），1 分钟内响应率 25.41% → 16.86%（-8.55pp）、3 分钟内 37.46% → 31.22%（-6.24pp），而 60 分钟内响应率仍有 88.21%——不是整体变慢，是少数会话的长尾把均值拉高了。同一时间买家咨询平均等待接待 5h48m → 7h08m（+79min / +22.8%），60 分钟内被人工接待率 64.81% → 57.55%（-7.26pp），排队体验同步变差。 弃单端是三个月里最好的一个月：最终弃单率 13.57% → 12.61%（-0.96pp），弃单数 10,525 → 10,303（-5.3%，日均）、金额 ¥101.6万 → ¥97.5万（-7.1%，日均）；确认订单数 21,315 → 24,500（+11.2%，日均），确认订单后发起的弃单率 15.90% → 12.92%（-2.98pp）。拆开看，改善主要来自「未呵护订单的弃单率大降」（33.94% → 21.02%），而呵护后的弃单率只是小幅下行（12.52% → 11.24%）。但同时要看到两个反向信号：物流呵护覆盖率 84.20% → 82.87%（-1.33pp），未呵护订单 3,368 → 4,196 张（+24.6%）；催付后付款率 25.99% → 21.61%（-4.38pp）。

结论与建议

主线是「弃单守住了，承接和时效在退」。三个月里最终弃单率 13.66% → 13.57% → 12.61%，弃单金额 ¥104.2万 → ¥97.5万，确认订单数反而 21,315 → 24,500（+11.2%，日均）；但同一时间接待覆盖率从 6.76% 掉到 5.55%，人工响应从 0h42m 拉长到 1h27m，每单的「有人第一时间接住」的概率在下降。弃单率的改善有相当一部分来自订单结构（确认订单占比 25.29% → 29.98%）与未呵护订单弃单率回落，并不全是服务能力提升的结果——这一点必须讲清楚，否则会把风险当成绩。 三个需要盯的口子。一是响应长尾：均值 1h27m 而 60 分钟内响应率仍有 88.21%，说明约一成长尾会话决定了整体观感；分账号看，HZH 10h11m（接待 62 人、转化 1.61%）、zhanghuaizhen 5h22m、wangjiaming 3h18m 三个账号是主要拖累；二是机器人沟通在缩量：机器人沟通的弃单数 5,903 → 4,126 → 3,458（三个月 -41%），弃单沟通率降到 38.66%，未沟通弃单已达 7,999 单（占 61.34%）；三是零触达的弃单原因：「Unpaid Order」1,209 单与「Seller did not Ship」536 单机器人沟通率均为 0%，合计 1,745 单完全没人碰。 建议下一周期：① 先治响应长尾——按账号设「超 30 分钟未响应自动转派 + 超 2 小时强制升级」规则，把 HZH / zhanghuaizhen / wangjiaming 三个账号（合计接待 248 人）的会话优先分流给 XJL / LJW / CPY（响应 0h07m / 0h07m / 0h12m），目标把 1 分钟内响应率从 16.86% 拉回 20% 以上；② 机器人沟通恢复量、并按原因分层——「Unpaid Order」「Seller did not Ship」两类共 1,745 单目前完全未触达，按机器人现有 30.45% 的挽回率估算，触达后约可多挽回 531 单 / 月；而「Failed Delivery」1,492 单机器人沟通率 24.26% 但挽回率仅 6.63%，应直接转人工；③ 把未呵护订单收干净——本期 4,196 张未呵护，弃单率 21.02%、比呵护后高 9.78pp，全部补上呵护约可少弃 410 单 / 月，同时复盘催付后付款率下滑（25.99% → 21.61%）的话术与时机。
